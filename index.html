Conversion rules

Initial Set (SCAS) — from Pack Details - IS. Each pack's units = Total Packs × Ratio. Delivery quantities come from the Store Summary table (Type = IS). For deliveries 2..n: ROUND(Total Packs ÷ Total IS Units × Delivery Units, 0) × Ratio; delivery 1 takes the remainder. Item No = LEFT(Color,6) & "-" & pack #. PCS Per Poly blank, Ratio = pack ratio.

Store REPL (SCSS) — one PO per REPL Date block in Pack Details - Store REPL. Item No = LEFT(Color,7) & "-" & Size, Qty = Repl Quantity, PCS Per Poly 1, Ratio = Vendor Pack.

Online REPL (SCSS) — Pack Details - Online REPL, PO suffix -DC-. Item No = LEFT(Color,5) & "-DC-" & Size.

PO numbering runs continuously: PG-IS-1, PG-IS-2, PG-REPL-3 … PG-DC-n. Ship Date = In-Store / REPL date − days, set separately for IS, REPL and DC (default 70 each).

SO Upload Template — same lines in the 20-column SO layout: Cancel Date = Ship Date, Order Date = date entered (default today), Ratio type Fixed, Ship to USA, ColorCode = Color name; Category, KIT, Carton UPC and SKU UPC left blank. Price = First Cost. Lines with zero qty are dropped.
